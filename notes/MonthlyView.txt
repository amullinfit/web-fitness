COMPONENT OVERVIEW
==================

MonthlyView is a new view component patterned after DailyView that displays workouts in a calendar-grid layout. It retrieves both planned and completed workouts and presents them in a flexible grid that adapts to desktop and mobile screen sizes.

KEY FEATURES
============

Data Management:
- Fetches planned workouts from /api/val-workouts
- Fetches historical/completed activities from /api/val-historical
- Merges and deduplicates workouts by date and type
- Retrieves sport settings for threshold pace calculations

Week Navigation:
- Starts at the current week (Monday of current week)
- Navigate backward/forward by week with Prev/Next Week buttons
- "This Week" button returns to current week
- Week label displays date range (Mon - Sun)

Responsive Grid Layouts:

DESKTOP LAYOUT:
- 7 columns (Monday - Sunday) × 4 rows tall
- Charts height: 80px (smaller than DailyView's 140px to fit grid)
- Allows scrolling forward and backward through weeks
- Full viewport height with scrollable grid area

MOBILE LAYOUT:
- 3 columns wide × 7 rows tall (one full week visible)
- Charts height: 60px (even smaller for mobile)
- Row 1 = Monday through Wednesday
- Row 7 = Friday through Sunday
- Each day cell scrolls independently for multiple workouts

WORKOUT DISPLAY
===============

Each day cell shows:
- Day name (Mon, Tue, Wed, etc.) 
- Date (e.g., "Sep 10")
- List of workouts for that day
- For each workout:
  * Sport/activity type
  * Workout name/title
  * WorkoutChart component (if intervals/workout_doc exists)
  * Visual status indicators

Workout Status Indicators:
- COMPLETED: Green background (#e8f5e9) - shows both planned and executed
- MISSED: Red/faded background (#ffebee) - past date with no completion
- TODAY: Blue border on current week's day cells
- Normal: Gray background for future/unstarted workouts

UTILITY FUNCTIONS
=================

getMondayOfWeek(date)
- Calculates the Monday of the week for any given date
- Used to determine week boundaries

getDatesByDay(startMonday)
- Generates array of 7 dates starting from a Monday
- Returns dates from Monday through Sunday

Helper functions inherited from DailyView:
- getLocalDateString(): Convert date to YYYY-MM-DD format
- getThresholdPaceForSport(): Get pace threshold for workout type
- isWorkoutCompleted(): Check if workout is completed
- safeStringLower(): Safely convert values to lowercase strings

STATE MANAGEMENT
================

Component State:
- workouts: Array of all loaded workouts
- sportSettings: Array of sport threshold pace settings
- loading: Boolean for loading state
- currentWeekMonday: Date object for start of current display week
- errorMessage: String for error notifications

Memoized Values:
- weekDates: Array of 7 dates (Monday-Sunday) for current view
- workoutsByDate: Map of dates to workout arrays for efficient lookup
- todayStr: Today's date string in YYYY-MM-DD format
